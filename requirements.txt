# ---------------------------------------------------------------------------
# DEPLOYMENT NOTES (Python 3.12 + mysql-connector-python 9.x)
#
# manage.py's db_config MUST include:  "use_pure": True
#   The 9.x default C extension's TLS stack hangs forever against the
#   DigitalOcean managed database and ignores connection_timeout, so it never
#   surfaces an error. The pure-Python driver connects normally.
#
# Do NOT pass ssl_ca="" (empty string). 9.x treats it as a real CA path and the
# TLS handshake stalls. Only set ssl_ca/ssl_verify_cert when a CA file exists.
#
# The removal server's IP must be added to the database's Trusted Sources in
# DigitalOcean, or connections time out (WinError 10060).
#
# The custom modules (broker_helpers, email_sender, etc.) live in `lib/` —
# lowercase. Python on Windows matches module case even though the filesystem
# does not, so a venv-created `Lib/` breaks `from lib.broker_helpers import ...`.
# ---------------------------------------------------------------------------
